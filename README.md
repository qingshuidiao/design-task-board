# 设计任务实时看板

一个轻量的设计组任务看板原型，用于按周和按月查看任务排期。支持任务新增、编辑、拖拽移动、日期调整、搜索筛选、导入导出、本地保存，以及可选的多人同步。

## 使用

直接打开 `index.html`，或在当前目录启动本地服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173
```

## 功能

- 周视图和月视图任务排期
- 新增、编辑、删除任务
- 拖拽移动任务和调整日期
- 按成员、状态、关键词筛选
- 本地保存
- JSON 导入导出
- 可选的云端多人同步

## 安全说明

多人同步需要自行配置后端服务和访问权限。请不要把密钥、真实成员邮箱、内部任务数据或权限规则细节提交到公开仓库。
