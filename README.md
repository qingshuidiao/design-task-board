# 设计任务实时看板

一个轻量的设计组任务看板原型，用于按周和按月查看任务排期。支持任务新增、编辑、拖拽移动、日期调整、搜索筛选、导入导出，以及基于 Supabase 的多人同步。

## 使用

如果只是看静态页面，可以直接打开 `index.html`。如果需要登录、多人同步或 Supabase 功能，请在当前目录启动本地服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173
```

不要用 `file://.../index.html` 做登录测试；本地文件模式下浏览器可能会拦截 Supabase 登录请求。

## 功能

- 周视图和月视图任务排期
- 一键回到今天所在周或所在月
- 月视图跨天任务以横向任务条展示
- 标记 2026 年国家法定节假日和调休补班日
- 新增、编辑、删除任务
- 拖拽移动任务和调整日期
- 按成员、状态、关键词筛选
- JSON 导入导出
- 云端多人同步

## 安全说明

多人同步需要自行配置后端服务和访问权限。请不要把密钥、真实成员邮箱、内部任务数据或权限规则细节提交到公开仓库。

## 节假日说明

当前节假日数据内置为 2026 年中国大陆法定节假日和调休补班日。每年国务院发布下一年度安排后，需要更新 `app.js` 里的节假日日期。
